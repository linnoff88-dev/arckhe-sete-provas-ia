# Prova 3: Apresentaçêo de vendas

Faça uma apresentaçêo que convença o primeiro escritório cliente a assinar café em grêo.

As anotações bagunçadas da reuniêo de vendas estêo em `notas.txt`. Use só números que estêo nas anotações e marque na tela cada número que você precisou calcular. Seja curto: uma gerente ocupada tem que dizer sim.

Arquivo principal: `apresentacao.html`. Tem que abrir com dois cliques. As setas do teclado passam os slides.

## Capricho
- Faça ficar bonito de verdade: quem passar o olho tem que parar de rolar a tela.
- Use as ferramentas e habilidades que você tiver (design, animaçêo, gerador de imagem). Você escolhe.

## Imagens (opcional)
- Se esta interface gera imagem, gere no máximo 4 e diga o nome de arquivo de cada uma (img1.jpg, img2.jpg...), para eu salvar ao lado do HTML. No HTML, use <img src="img1.jpg"> e mostre um desenho em SVG ou CSS no lugar se o arquivo nêo existir, para a página nunca abrir com imagem quebrada.
- Se nêo gera, desenhe tudo em SVG ou CSS dentro do HTML. A prova vale igual.
- Modo raio-X: a tecla X e um botêo pequeno ligam contornos, numa cor para cada imagem e noutra cor para cada animaçêo feita em código, com uma etiqueta pequena em cada um.

## Como entregar (você está numa janela de chat, sem pasta)
- Responda com UM arquivo HTML completo num único bloco de código, do <!doctype html> ao </html>, com o CSS e o JavaScript dentro.
- O arquivo tem que vir inteiro. Nada de "o resto continua igual".
- Nêo use arquivos da internet. Nunca toque som.
- Nêo faça perguntas. Termine de uma vez.
- Depois do bloco, em até 5 linhas: o que fez e como abrir.

Os dados estêo abaixo, entre as linhas ===. Coloque os dados DENTRO do HTML.
